# 钱伲 · 小红书内容运营套件

给「钱伲」（iOS 手动记账 App，¥38 买断）做**合规的内容运营**。
所有产出放在这里，由你**审核后手动发布**。本套件不包含任何自动化发帖 / 私信行为。

## 文件导航

| 文件 | 用途 |
|---|---|
| `README.md` | 本文件，总览与使用说明 |
| `strategy.md` | **策略核心**：定位、人设、人群、内容支柱、¥38 叙事、合规红线、转化路径 |
| `content-calendar.md` | 冷启动 4 周排期 + 长期节奏 + 每周复盘 |
| `posts/` | **成品文案**（13 篇，可直接复制发布），一篇一文件 |
| `reply-templates.md` | 评论区 / 私信回复话术（你本人回复真实留言用） |
| `assets.md` | 配图映射：哪篇用哪些截图，及截图使用注意 |

## 怎么用

1. 先读 `strategy.md`，确认人设与红线你是否认同。
2. 按 `content-calendar.md` 的排期，从 `posts/` 取对应文件。
3. 文案里凡出现 `（填：…）` 的地方，是你本人才能提供的真实信息，**发布前补上，不要编**。
4. 配图按 `assets.md` 从 `tools/appstore-assets/screenshots/` 取真机截图。
5. 发布后按 `reply-templates.md` 回复评论。

## 三条铁律（写在最前面）

1. **不自动发帖、不自动私信、不批量关注** —— 平台风控红线，账号会废。
2. **只写为真的事** —— 无广告 / 无追踪 / 无需注册 / 数据在自己 iCloud / 家庭共享。
   绝不写「数据不上传服务器」（走 CloudKit，是假的）。
3. **不编数、不伪造口碑** —— 下载量、评分、用户评价、开发时长，能填真数就填，不能就换措辞。

> 相关约束来源：`tools/appstore-assets/README.md`（可证实性）、`tools/appstore-assets/metadata.md`（官方定位口径）。
