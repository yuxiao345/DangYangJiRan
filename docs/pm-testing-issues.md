## 待修复

### #1 预算计划 - 日期选择器选完后不自动关闭

- **发现日期**：2026-05-25
- **影响页面**：新建预算计划 / 编辑预算计划（`AddEditBudgetBookView.swift`）
- **问题描述**：在「预算周期」区域的「开始日期」「结束日期」点击后弹出日历控件，选取目标日期后日历控件不会自动关闭，需要点击旁边空白区域才会收起。
- **期望行为**：在日历控件中选择日期后，立即选取该日期并自动关闭日历控件。
- **技术原因**：iOS Form 中 DatePicker 默认使用 `.compact` 样式，弹出的日历 popover 在点击日期后不自动 dismiss，是系统默认行为。需要自定义交互逻辑。
- **涉及文件**：`FirstCC/Views/Budgets/AddEditBudgetBookView.swift:31-32`
